ANCHOR Studio for Windows (portable version)
by A. Mamdouh Kastour · A. Mamdouh Kastour’s Scholarly Anchor

Double-click "Start ANCHOR Studio.bat". The app opens in its own window
(Microsoft Edge app mode, or your default browser). Everything it needs, R and
all R packages, is inside this folder. Nothing else needs to be installed.

A minimised "ANCHOR Studio" window appears in the taskbar while the app runs.
The app stops by itself about 20 seconds after you close its window.
Your work is autosaved every minute. On the next start, the Start tab offers
"Resume last session".

Keep this folder somewhere you can write to, for example Documents.
Do not run it from inside the zip file.
